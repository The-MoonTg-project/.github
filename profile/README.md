# The Moon-Userbot Project

Welcome to the official home of **Moon-Userbot** on GitHub! We are dedicated to building a simple, fast, and highly customizable AI-powered Telegram userbot ecosystem. We stand on the shoulders of the giants who came before us.

---

## Project Overview

The Moon-Userbot Project provides a modular framework for Telegram userbots, emphasizing speed, simplicity, ease of deployment, and native integration with modern Large Language Models. Originally developed as a successor to abandoned projects, it has evolved into a comprehensive suite for power users and developers.

### Key Features

* **Multi-Model AI Support:** Native integration for Gemini Pro, ChatGPT, Cohere Coral and many more LLMs.
* **Media Generation:** Built-in tools for SDXL, DALL-E 3, and image upscaling.
* **Deployment Flexibility:** Support for Android (Termux), Linux, Docker, and specialized cloud environments.
